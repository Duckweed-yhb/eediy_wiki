# 前言

> 一份面向电气电子工程（EE）方向的中文自学指南：把散落在教材、厂商手册、视频和论坛里的课程、教材与实验资源，按一条自学者能走通的成长路线重新组织起来。

## 为什么会有这个站

很久之前我偶然看到了 [csdiy.wiki](https://csdiy.wiki/)（CS 自学指南），深受启发。CS 方向已经有人把国内外名校的公开课、教材与实践路线系统地汇总到一起，自学者沿着它就能拼出一条完整的学习路径。

而 EE / 电气方向一直缺少同等组织程度、面向自学者的中文资源集合。电路、模电、信号与系统、电机控制、电力系统……知识点散落在各家教材、半导体厂商手册、B 站视频和技术论坛里，入门者很难靠自己把它们串成一条从数理基础到完整工程的路线。

2026 年，Agent 与 AI 工具的发展，让人第一次有能力把资料调研、课程筛选、整理归档、持续迭代这件事做起来——AI 可以辅助检索、整理与写作，但最终由作者本人筛选、核对、对每一条内容负责。这就是这个站的由来：不是 AI 生成的资料堆砌，而是一份人在把关、可持续维护的 EE 自学路线。

## 自学 EE 的好处

- **进度自定**：可以按自己的节奏反复看某一节，不用跟着学期 DDL 赶。
- **视频可重复**：一段 PMSM FOC 的推导没听懂，倒回去看十遍也没人催。
- **博采众长**：MIT OCW、UC Berkeley、国内 MOOC 的同一门课可以对着看，不同教授讲同一个概念往往能互相补全。
- **时间自由**：在校、休学、在职都能安排，随时可以为项目暂停理论，再为理论回头补课。

## 自学 EE 的难处

- **师生交流缺位**：没有助教答疑，实验出问题只能靠报错信息和论坛搜索。
- **英文资源门槛**：最好的课程、datasheet 和应用笔记大多是英文，需要一定的阅读耐心。
- **自律与 DDL 缺位**：没有人给你交作业的节点，容易陷入「一直在看课、从不做实验」的舒适区。
- **硬件实验需要实物或仿真平台配合**：EE 不是纯软件，面包板、示波器、开发板和仿真软件都得自己搭。

## 这份指南适合谁

- 在校或休学期间想按自己路线重排 EE 课程的同学；
- 从其他方向转电气 / 嵌入式 / 电力的自学者；
- 打电控类竞赛、需要一条从电路到 FOC 的快速上手路线的人；
- 准备考研复试、需要把知识体系重新结构化的考生；
- 准备就业、想用项目串起课程的求职者。

也不必从头到尾读——按方向选板块即可，做哪个方向的项目就查哪个板块。

## 如何使用本指南

- 先读 [路线地图](/roadmap) 看板块之间的前置依赖与硬件→软件分层；再读 [路线总览](/README) 看 8 个板块各自的定位。
- 按 01 → 08 的顺序打主线，或按需跳到当前项目相关的板块。
- 单门课程看板块 README 里的卡片：课程官网、视频、教材、作业实验、自学建议。
- 跨方向汇总的电子书、公开课、资源网站与工具清单见 [附录](/appendix/README)。
- 自己整理的笔记放进对应板块的「我的笔记」分区。

## 一个仅供参考的学习规划

呼应 [路线地图](/roadmap) 的五阶段，给一个粗略的时间盘（按业余学习计，全职可压缩）：

1. **基础打底**（约 3–6 个月）：[01 数理与编程基础](/01-math-programming/README)——高数、线代、概率统计、大学物理、C 语言。
2. **硬件入门**（约 2–4 个月）：[02 电路与电子学](/02-circuit-electronics/README) 加 [06 信号与通信](/06-signal-communication/README)——电路原理、模电数电、信号与系统。
3. **数字平台**（约 2–4 个月）：[03 嵌入式与单片机](/03-embedded-mcu/README) 与 [07 数字逻辑与 FPGA](/07-digital-fpga/README)——MCU 外设驱动、RTOS、Verilog 与 FPGA 工程流程。
4. **系统集成**（约 3–6 个月）：[04 电机与运动控制](/04-motor-control/README) 或 [05 电力系统](/05-power-system/README)——选一个方向做完整闭环项目。
5. **按需查阅**：[08 硬件工具链](/08-hardware-toolchain/README) 不单独排阶段，做项目时回查 PCB、仿真、测量与版本管理工具。

时间只是参考，重要的是每一阶段都配一个能跑起来的小项目。
