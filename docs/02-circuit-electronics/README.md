# 02 电路与电子学 · Circuits & Electronics

从电路原理到模拟、数字电路：先会算电阻、电容、电感与交直流电路，再看得懂放大、滤波、运放电路与逻辑门。这是动手做硬件板子的入门层。

## 路线位置

- **前置**：[01 数理与编程基础](../01-math-programming/README.md)。
- **通往**：[03 嵌入式与单片机](../03-embedded-mcu/README.md)、[07 数字逻辑与 FPGA](../07-digital-fpga/README.md)、[04 电机与运动控制](../04-motor-control/README.md)。
- **学习顺序建议**：电路原理先行，模电、数电可并行；做板子前先把常用器件和基本电路过一遍。

## 习题、实验与动手练习

- **电路课后题**：邱关源《电路》每章精选习题手写推导，重点做戴维南等效、一阶瞬态、相量法分析。
- **LTspice 仿真实验**：每学完一个电路（分压、RC 充放电、共射放大），在 LTspice 里搭一遍并对比手算结果。下载地址：https://www.analog.com/resources/design-tools-and-calculators/ltspice-simulator.html
- **Multisim 仿真**：哈工大 / 清华 MOOC 配套实验，适合模电放大电路与数电逻辑门仿真。
- **立创 EDA 在线仿真**：https://lceda.cn/ ，国产在线电路设计工具，可做简单电路仿真与 PCB 绘制。
- **面包板实操**：买一套面包板 + 杜邦线 + 常用电阻电容 LED，搭分压电路、RC 闪烁灯、运放反相放大。

## 项目实战

### 入门

- **面包板 RC 呼吸灯**：用 555 定时器或 RC 充放电电路驱动 LED 呼吸效果。目标：理解电容充放电时间常数。工具：面包板、电阻、电容、LED、555 芯片。
- **反相比例运算放大器**：用通用运放（如 μA741）搭一个反相放大器，用信号发生器输入正弦波，示波器观察输出。目标：掌握运放虚短虚断分析。工具：面包板、μA741、±12V 电源、示波器。

### 进阶

- **晶体管音频放大电路**：用 LM386 或分立 BJT 搭一个小功率音频放大器，接手机输出听声音。目标：理解增益、带宽、阻抗匹配。工具：面包板、LM386、扬声器、电容电阻。
- **组合逻辑表决器**：用 74LS 系列逻辑门搭一个三人多数表决电路，真值表验证。目标：掌握组合逻辑设计。工具：面包板、74LS00 / 74LS08、LED。

### 综合

- **数字时钟（时分秒）**：用 74LS 系列计数器 + 七段数码管搭一个 24 小时制数字时钟。目标：综合运用时序逻辑、计数器、译码器。工具：面包板、74LS90 / 74LS47、共阳数码管、晶振。
- **简易示波器前端**：用运放搭一个衰减 + 放大前端电路，把待测信号调整到 ADC 量程内，接单片机采样后串口上传电脑画图。目标：模拟电路 + 数采结合，为 03 / 06 板块铺路。
