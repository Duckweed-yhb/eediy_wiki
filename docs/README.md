# EE 自学路线总览

本 Wiki 按电气电子工程（EE）的成长顺序把内容分成 8 个板块。每个板块页面再细分公开课、教材、习题实验、项目实战与自己的笔记。

> 想看图形化的全局关系：[路线地图](./roadmap.md) 提供课程前置依赖图与硬件→软件分层架构图；跨板块的电子书、公开课、资源网站与工具清单见 [附录](./appendix/README.md)。

## 推荐学习顺序

1. **01 数理与编程基础**：C 语言与高数、概率、物理并行，先把计算和第一门语言过关。
2. **02 电路与电子学**：电路原理打底，模电、数电跟进，看懂基本电路与逻辑门。
3. **06 信号与通信**：信号与系统、频域分析，为控制与滤波打基础。
4. **03 嵌入式与单片机**：在 MCU 上练外设驱动，从裸机过渡到 RTOS。
5. **04 电机与运动控制**：电机模型、FOC 与闭环控制，仿真先行、再上板实测。
6. **05 电力系统**：潮流、调度与优化算法，结合平台做集成。
7. **07 数字逻辑与 FPGA**：并行硬件描述与时序工程。
8. **08 硬件工具链**：不单独安排阶段，做项目时按需查阅。

## 填写约定

- 新增一门课程或一份笔记：复制 [`templates/course-template.md`](./templates/course-template.md)，放进对应板块目录，并回到该板块 README 的「我的笔记」补一行链接。
- 资源条目统一写：名称 + 链接 + 一句话说明；自己的笔记放在「我的笔记」，外部课程 / 教材放在对应资源分区。
- 还没收集到的内容保留「（待补充）」占位，不凭印象填课程名或链接。
