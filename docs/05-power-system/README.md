# 05 电力系统 · Power Systems

电力系统分析与优化：潮流计算、机组组合、经济调度、多约束最优运行，以及标准测试系统接入、可视化结果输出与算法扩展。

## 路线位置

- **前置**：[01 数理与编程基础](../01-math-programming/README.md)（线性代数、优化基础）、[02 电路与电子学](../02-circuit-electronics/README.md)。
- **通往**：电力系统仿真平台、能源监测与自动化项目。
- **学习顺序建议**：先掌握潮流与网络模型，再学习调度与优化算法，最后在平台上集成标准测试系统。

## 核心公开课与课程

> 本板块分三条主线：**电力系统分析基础**（潮流、节点导纳矩阵、有功无功）→ **稳态/暂态与稳定**（故障、同步机摇摆、电压频率）→ **经济运行与调度优化**（等耗量微增率、机组组合、OPF）。中文课以华科《电力系统分析》何仰赞教材体系为主干，英文课用 NPTEL 补动态与运行控制视角。

## 习题、实验与动手练习

- **节点导纳矩阵手算**：对 5 节点以内小网络手算节点导纳矩阵，再与 pandapower 结果对照。完成方式：纸笔 + Python 脚本输出矩阵。
- **牛顿-拉夫逊潮流算例**：在 pandapower 中加载 case9 / case14，跑牛顿法潮流，对比 PQ 分解法收敛迭代次数。完成方式：Python 脚本 + 电压/相角结果表。
- **MATPOWER 标准算例**：在 MATLAB 或 Octave 中跑 MATPOWER `case9`、`case30`，观察 OPF 结果与节点边际电价。完成方式：MATLAB 命令输出。
- **短路故障计算**：手算三相短路与单相接地短路电流，用 pandapower `short_circuit` 对照。完成方式：纸笔 + Python。
- **经济调度算例**：两机组并联供电，按等耗量微增率准则手算有功分配，再用 PuLP/CVXPY 求解对照。完成方式：Python 优化脚本。
- **机组组合入门**：在 MATPOWER 或 pandapower 框架上，跑一个简化的 24 小时、3 机组 UC 问题（0-1 启停变量 + 爬坡约束）。完成方式：Python + PuLP 整数规划。

## 项目实战

### 入门级：九节点潮流可视化

- **目标**：用 pandapower 加载 IEEE 9 节点标准系统，跑潮流计算，输出各节点电压、各支路功率，并画成简单拓扑图。
- **工具**：Python、pandapower、matplotlib。
- **参考方向**：pandapower 官方 docs 入门示例 https://pandapower.readthedocs.io/ 。

### 进阶级：区域电网经济调度优化器

- **目标**：给定若干火电机组耗量特性与负荷曲线，在满足功率平衡、机组上下限、爬坡约束下，求解 24 小时发电计划，最小化总燃料成本。
- **工具**：Python、PuLP / CVXPY、pandapower。
- **参考方向**：NPTEL Power Systems Operation and Control 大纲对应章节；MATPOWER OPF 算例作对照。

### 综合级：标准测试系统接入与多约束 OPF 平台

- **目标**：在 pandapower 基础上集成 IEEE 14/30/57 节点标准系统，实现 AC 潮流 + 最优潮流（含线路容量约束、电压约束），输出可视化报表与 CSV 结果，预留风电/光伏节点扩展接口。
- **工具**：Python、pandapower、pandas、matplotlib/Plotly。
- **参考方向**：MATPOWER 官方算例库 https://matpower.org/ ；pandapower 官方文档；不挂未核实第三方仓库，基于官方工具链自研。
