# 08 硬件工具链 · Hardware Toolchain

做硬件绕不开的工具与流程：原理图 / PCB 设计、示波器与测量仪器、电源与调试手段，再配合版本管理、文档与笔记工具。这一板块不教原理，只记录每个工具的选型、上手要点与踩坑。

## 路线位置

- **前置**：无强制前置，随 02–07 各板块边做边查。
- **覆盖范围**：原理图 / PCB、仿真、编程器 / 调试器、测量仪器、数据与文档管理。
- **使用方式**：按工具登记，不按课程顺序学习；需要哪个看哪个。
- **跨板块工具索引**：软件与工具分类导航见 [附录 · 软件与工具清单](../appendix/tools.md)；本页记录具体上手笔记与踩坑。

## 原理图与 PCB

> 从立创 EDA 入门画第一块板，再按项目复杂度升级到 KiCad / Altium；Proteus 用于单片机先行仿真。

### 立创 EDA（嘉立创 EDA）

- **官方站点 / 文档**：<https://lceda.cn/> ｜ 用户指南：<https://docs.lceda.cn/>
- **上手要点**：国产免费、网页 / 客户端双端，与立创商城物料、PCB 打样 / SMT 贴片一条龙打通，元件库极全。新手第一个动作：浏览器打开 `lceda.cn/editor`，照着官方「两小时入门」教程画一个 LED 闪烁板并下单打样。适合 02、03 方向快速出板。
- **对应板块**：02 电路与电子学、03 嵌入式与单片机。

### KiCad

- **官方站点 / 文档**：<https://www.kicad.org/> ｜ 文档：<https://docs.kicad.org/>
- **上手要点**：跨平台、开源免费、无层数 / 引脚数限制，社区库与 PCM 插件生态成熟，是 Altium 之外最主流的选择。新手第一个动作：从官网 Download 页装 Windows 版，跟着官方 Getting Started 做一个两级运放放大板。适合不想被云绑定、需要多层板与自定义封装的项目。
- **对应板块**：02 电路与电子学、03 嵌入式与单片机、07 数字逻辑与 FPGA。

### Altium Designer

- **官方站点**：<https://www.altium.com/altium-designer>
- **上手要点**：工业界事实标准的专业级多层 PCB 设计软件，与 Altium 365 协同；订阅制、仅 Windows，学生可申请教育许可。新手第一个动作：在学校机房或教育版里跟官方「New to Altium Designer」教程画四层板。求职 PCB 岗前建议熟悉。
- **对应板块**：02 电路与电子学、03 嵌入式与单片机。

### EasyEDA

- **官方站点**：<https://easyeda.com/>
- **上手要点**：立创 EDA 的国际版，在线原理图 + PCB + SPICE 仿真一体，轻量上手快；国内账号与国际版不互通。新手第一个动作：在 EasyEDA 里克隆一个开源工程看结构。适合海外开源项目协作与快速验证。
- **对应板块**：02 电路与电子学、03 嵌入式与单片机。

### Proteus

- **官方站点**：<https://www.labcenter.com/>
- **上手要点**：原理图仿真 + 单片机（8051 / AVR / STM32 / ARM）联调一体化，不用写一行代码就能在 PC 上看到 IO 口波形与屏显，教学场景极多。新手第一个动作：用官方 8051 例程跑通 LED 闪烁 + 串口打印，再把自己的 Hex 灌进去看效果。适合 03 方向先仿真再上板。
- **对应板块**：03 嵌入式与单片机。

## 仿真与计算

> 模拟小信号用 LTspice / Multisim，系统级控制与电机闭环用 MATLAB / Simulink 或 PLECS，数据后处理用 Python。

### LTspice

- **官方站点**：<https://www.analog.com/resources/design-tools-and-calculators/ltspice-simulator.html>
- **上手要点**：ADI 免费提供的高性能 SPICE，原生模型库覆盖绝大多数 ADI / Linear 电源与运放，仿真速度快。新手第一个动作：下载后打开自带的桥整流 + 电容滤波例程，跑瞬态仿真看波纹。电源、模拟前端首选。
- **对应板块**：02 电路与电子学、05 电力系统。

### Multisim

- **官方站点**：<https://www.ni.com/en-us/shop/product/multisim.html>
- **上手要点**：NI 出品的图形化 SPICE，虚拟仪器（示波器、万用表、信号源）面板直观，国内模电 / 电路教材配套实验多用它。新手第一个动作：拖出一个运放 + 信号源 + 示波器，接成反相放大器测幅频。适合课堂实验与教学。
- **对应板块**：02 电路与电子学。

### MATLAB / Simulink

- **官方站点**：<https://www.mathworks.com/>
- **上手要点**：控制系统建模、电机 FOC 闭环、信号处理与数值分析的行业标准；学校一般有校园许可。新手第一个动作：先在 MATLAB 命令行跑通 `plot` 与传递函数 `tf`，再在 Simulink 里拖一个 PID 控制一阶环节看阶跃响应。04 电机方向必用。
- **对应板块**：04 电机与运动控制、05 电力系统、06 信号与通信。

### PLECS

- **官方站点**：<https://www.plexim.com/products/plecs>
- **上手要点**：专攻电力电子与电机系统时域仿真，开关器件用理想开关、步长可拉大，仿真速度远快于通用 SPICE；教育版 / 试用版可申请。新手第一个动作：跑官方三相逆变器 + PMSM 例程，改 PI 参数看 dq 轴响应。电力电子方向首选。
- **对应板块**：04 电机与运动控制、05 电力系统。

### Python（NumPy / SciPy / Matplotlib）

- **官方站点**：<https://www.python.org/> ｜ 库：<https://numpy.org/> ｜ <https://matplotlib.org/>
- **上手要点**：免费、跨平台，做实验数据处理、频谱分析、算法原型比 MATLAB 更灵活；配合 Jupyter Notebook 边算边画图。新手第一个动作：装 Anaconda，在 Notebook 里用 `numpy.fft` 对一段实测串口数据做频谱。
- **对应板块**：01 数理与编程基础、06 信号与通信。

## 测量与调试

> 仪器是硬件工程师的眼睛：示波器看波形、电源供可调电、万用表测通断、逻辑分析仪抓数字协议、串口助手看 MCU 日志。

### 数字示波器

- **官方站点（常用国产 / 入门）**：RIGOL（普源）<https://www.rigol.com/>；SIGLENT（鼎阳）<https://www.siglent.com/>
- **上手要点**：入门选 100 MHz 带宽、2 通道即可，关注采样率与存储深度。新手第一个动作：接信号发生器 1 kHz 方波，调触发与档位让波形稳定站住，再用 Measure 自动测峰峰值与频率。
- **对应板块**：02 电路与电子学、04 电机与运动控制、08 硬件工具链。

### 直流电源

- **说明**：实验室线性电源 / 可调开关电源，关注输出电压电流范围、纹波与三路独立输出；常用国产型号（Rigol、ITECH、汉诺）见各校实验台。
- **上手要点**：上电前先把电压旋钮拧到最小、限流设成目标值 1.2 倍，再接负载；新手第一个动作：设 5 V / 0.5 A，接一个 USB 电压表看输出。
- **对应板块**：02 电路与电子学、03 嵌入式与单片机。

### 数字万用表

- **说明**：入门选自动量程真有效值（TRMS）手持表（优利德、FLUKE 17B 级）；关注直流电压精度与通断蜂鸣。
- **上手要点**：先测电压、再测电阻、最后测通断；大电流挡不要忘了换表笔孔。新手第一个动作：测一节 5 号电池电压，再量自己焊的 LED 板各路供电。
- **对应板块**：02 电路与电子学、03 嵌入式与单片机。

### 逻辑分析仪（sigrok / PulseView）

- **官方站点**：<https://sigrok.org/>
- **上手要点**：开源跨平台，配合廉价 HW-USB 或 Saleae 兼容硬件，可解码 UART / SPI / I2C / CAN。新手第一个动作：用 24 MHz 廉价逻辑分析仪夹在 STM32 的 I2C 总线上，在 PulseView 里抓出 OLED 读写时序。比示波器便宜且能同时看 8–16 路。
- **对应板块**：03 嵌入式与单片机、07 数字逻辑与 FPGA、08 硬件工具链。

### 串口调试助手

- **说明**：Windows 常用 SSCOM / XCOM，跨平台用 PuTTY / minicom / `screen`；VS Code 可装 Serial Monitor 插件。
- **上手要点**：USB 转串口（CH340 / CP2102）装好驱动，波特率与 MCU 工程一致（常用 115200 8N1）。新手第一个动作：把开发板 USB 插入后在设备管理器找到 COM 口，打开助手看到 Hello World 打印。
- **对应板块**：03 嵌入式与单片机、08 硬件工具链。

## 开发与版本管理

> 代码与文档都进 Git，编辑器统一 VS Code，工程按规范组织目录。

### Git

- **官方站点**：<https://git-scm.com/> ｜ 可视化客户端推荐 GitHub Desktop / VS Code 内置 Git
- **上手要点**：硬件工程的固件、原理图、PCB 工程文件都要版本化；`.gitignore` 忽略编译产物与大二进制。新手第一个动作：装好 Git 后在本地仓库 `git init` → `git add .` → `git commit -m "init"`，再推到 GitHub。
- **对应板块**：08 硬件工具链。

### VS Code

- **官方站点**：<https://code.visualstudio.com/>
- **上手要点**：免费通用编辑器，装 C/C++、PlatformIO、Python、Markdown 插件后可做嵌入式开发与笔记；配合 Remote-SSH 连服务器。新手第一个动作：装 C/C++ 与 Python 扩展，打开一个 .c 文件看智能提示。
- **对应板块**：03 嵌入式与单片机、07 数字逻辑与 FPGA、08 硬件工具链。

### 工程组织与文档规范

- **说明**：嵌入式工程推荐 `Core/`、`Drivers/`、`App/`、`Docs/`、`Hardware/`（原理图 PDF + PCB 出库文件）、`Test/` 分层；README 写清接线与编译步骤。
- **上手要点**：每个硬件项目仓库根目录放一张接线图（draw.io 导出 PNG）+ 一份烧录说明。新手第一个动作：照着 STM32CubeIDE 生成的工程结构，把自己的应用代码挪到 `App/` 并写一份 README。
- **对应板块**：03 嵌入式与单片机、08 硬件工具链。
