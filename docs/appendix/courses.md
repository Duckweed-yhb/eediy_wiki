# 公开课与慕课平台

汇总可用于 EE 自学的公开课平台；具体某门课程仍按方向登记到对应板块 README 的「公开课」分区。

## 常用平台

| 平台 | 链接 | 特点 | 适合方向 |
|---|---|---|---|
| MIT OpenCourseWare | <https://ocw.mit.edu> | 完整课程讲义、习题与录像，理工基础扎实 | 数理、电路、信号、算法 |
| UC Berkeley EECS | <https://www.eecs.berkeley.edu/> | 名校 EE / CS 课程网站与公开资料 | 编程、电路、信号、体系结构 |
| Coursera | <https://www.coursera.org> | 系统化课程、可旁听，含作业与测验 | 控制、信号、嵌入式、机器学习 |
| edX | <https://www.edx.org> | 高校合作课程，工程与电子方向齐全 | 电路、电子、计算机体系结构 |
| NPTEL | <https://nptel.ac.in> | 印度理工学院公开课程，EE 工程系列完整 | 电路、电机、电力系统、控制 |
| 中国大学 MOOC | <https://www.icourse163.org> | 国内高校中文课程，贴合国内教材体系 | 电路、模电、数电、信号与系统 |
| 学堂在线 | <https://www.xuetangx.com/> | 清华等高校出品，中文课质量高 | 模电、自控、电路 |
| 国家智慧教育平台 | <https://higher.smartedu.cn/> | 教育部官方慕课平台，国家级精品课免费 | 全部方向（中文） |
| B 站 | <https://www.bilibili.com> | 中文课程录像与实操教程，适合入门跟练 | 全部方向（选口碑 UP 主课程） |
