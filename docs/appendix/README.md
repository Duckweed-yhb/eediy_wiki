# 附录 · 资源汇总

附录把**跨板块**的外部资料集中归档：电子书与经典教材、公开课与慕课平台、资源与参考网站、软件与工具清单。

> **定位约定**：某个板块专属的课程、教材、习题仍登记在对应板块 README 的资源分区；这里只做跨板块的汇总导航，避免同一处内容重复维护。尚未收集到的条目保留「待补充」占位，不凭印象填写课程名或链接。

## 使用方式

- 找某门课：先回到对应板块 README 的「公开课 / 教材与参考书」；这里只汇总平台与跨方向经典书目。
- 找某个工具：在 [tools.md](./tools.md) 按类别定位，上手笔记与踩坑记录写进 [08 硬件工具链](../08-hardware-toolchain/README.md)。
- 新增条目统一格式：**名称 + 链接 + 一句话说明 + 对应方向**；自己的笔记不放在附录，归到所属板块的「我的笔记」。
